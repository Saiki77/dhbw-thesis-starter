# English skeleton

`lang/en/` mirrors the language-specific files under `thesis/` in English:
chapters, cheat sheet, abstract, glossary, abbreviations and the example
bibliography. Run `./set-language.sh en` to install it, or
`./set-language.sh de` to keep the German skeleton. Either way this folder is
deleted afterwards, so the thesis exists in one language only. Do not edit the
files here; edit the ones in `thesis/`.
